# 🏠 House Price Prediction Web App

A complete end-to-end **Machine Learning + Flask** web application that predicts house prices based on basic property features and displays analytics using an interactive dashboard.

This project demonstrates the full workflow from model training to a modern web interface.

---

## 🚀 Project Features

- Predicts house price using:
  - Size (sq ft)
  - Number of Bedrooms
  - Age of the House
- Machine Learning model using **Linear Regression**
- Beautiful responsive UI
- Input validation & flash messages
- Interactive Dashboard with:
  - Size vs Price Line Chart
  - Average Price per Bedroom Bar Chart
- Clean project structure and reusable design

---

## 🧠 Machine Learning Details

- Algorithm: Linear Regression
- Libraries:
  - Pandas
  - NumPy
  - Scikit-learn
- Model saved using Joblib and integrated with Flask backend
